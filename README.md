# ⚡ VoltZone

VoltZone is a connected EV and energy hub with backup access for nearby areas.

---

## 🚀 What it does

* Charge electric vehicles 🔋
* Provide access to EV rentals 🚗
* Power everyday devices 🔌
* Offer backup power during outages ⚡

---

## 🧠 Idea

VoltZone brings together mobility and energy in one place.

It allows people to access electric vehicles, stay powered, and rely on nearby energy support when needed.

---

## 🔧 Features (MVP)

* EV charging points
* EV access / rentals
* Device charging access
* Location-based discovery

---

## 🌐 Vision

To create a network of local energy hubs that make electric mobility and power accessible everywhere.

---

## 🛠️ Tech (planned)

* React / Next.js
* Firebase / Supabase
* Maps API
